# QBLOCK website

This folder is a self-contained static website for QBLOCK by Yup.

## Files

- `index.html` — page markup, copy, SEO metadata, and accessible interactions
- `styles.css` — responsive visual system, game-card illustrations, motion, and layout
- `script.js` — mobile navigation and scroll reveal behavior
- `assets/` — the provided QBLOCK character images and Yup logo

Open `index.html` directly in a browser or serve this folder with any static web server.

The page intentionally includes Discord as the only community call-to-action.
